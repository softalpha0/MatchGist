# legacy/: Touchline prototype

This is the first prototype, built before the project became MatchGist. It still runs (`pip install -e legacy[foundry]`)
and is kept as a source of parts. Pieces move into `backend/app/` one milestone at a time (the simulator in M1;
stats, the verifier and the Agent Framework wiring in M2 and M3). This folder is deleted before submission.
