# Demo video script (under 2 minutes)

Record from the Netlify link in a fresh browser window at full screen. No music, or royalty-free only. Speak
slowly; the timings leave room.

| Time | On screen | Say |
|---|---|---|
| 0:00-0:12 | Landing page hero | "A match reaches millions of fans at once. But match intelligence assumes a big screen, fast data and English. Everyone else gets a scoreline." |
| 0:12-0:22 | Click **Watch it live**. Pick **Late drama**, press **Kick off** | "MatchGist takes a stream of synthetic match events and tells the same match to six fictional fans, each on their own channel, budget and language." |
| 0:22-0:40 | Let it play at 30x. Point at the devices, then the data meters | "Jakarta gets SMS in Bahasa on a 1 MB plan. Delhi gets Hindi SMS, where one Hindi letter cuts a message from 160 characters to 70. Lagos gets Pidgin voice notes, Dubai a watch glance in Arabic. Each device shows the bytes used, pings left and which limit binds." |
| 0:40-0:55 | Press **Jump → 85'**. Watch the equaliser and the winner land | "Here's the late drama. The same goal arrives six different ways. Jakarta only follows Riverside, so the Budget Guard skips Northgate's winner for them. São Paulo has one ping left, so it's kept for the full-time digest." |
| 0:55-1:05 | Point at the System panel | "Every decision is visible: the Ranker's score, the Budget Guard's send, hold or skip, and the Verifier." |
| 1:05-1:30 | Tap **why?** under the Delhi Hindi SMS | "Every message is explainable. Here are the facts the Stats Engine detected, the six match events behind them with player, time and pitch position, and each agent step. The model only writes words; every number must come from these facts, and a Verifier checks each one, plus the real SMS segment count, before anything is sent." |
| 1:30-1:45 | Close the drawer. Press **Jump → FT**. Point at the green digests | "At full time, each fan gets a recap sized to whatever is left of their budget." |
| 1:45-1:58 | Back to the landing page or the README | "Built on Microsoft Agent Framework: an Explainer, then a separate workflow per fan with a Verifier retry loop. Across four recorded matches, 193 messages, every one written by the model and verified. MatchGist: the match, sized to fit every fan." |

Before recording: open the site once so it's cached, close other tabs, and do one practice run.
