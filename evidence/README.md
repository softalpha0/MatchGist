# Evidence

Each file here is generated by `python -m app.record` from a full run of one synthetic match through the real
pipeline: simulator, Stats Engine, Moment Detector, then the agent workflow for six fans. The same run is saved
as `frontend/public/replays/<storyline>.json`, which is exactly what the live site plays.

| File | Match |
|---|---|
| [late_drama.md](late_drama.md) | 1-2: an 89th-minute equaliser, then a winner in stoppage time |
| [comeback.md](comeback.md) | 2-3: Northgate come back from 2-0 down |
| [red_card.md](red_card.md) | 4-2: a red card at 67', then three more goals |
| [none.md](none.md) | 1-2: an open game with no storyline bias |
| [auto-eventing.md](auto-eventing.md) | Passes, distance and ball speed detected from a synthetic match video, scored against the truth |

Each file has:

- **Grounding check:** how many messages passed the Verifier, how many were sent back to the Compressor, and
  how many fell back to a template.
- **Every key moment** (score 50+): the facts the Stats Engine detected, and the 6 source events (trigger last)
  with time, type, player, team and pitch coordinates.
- **What three kinds of fan received** for that moment: the studio overlay (English), an SMS in Hindi or Bahasa,
  and an Arabic watch glance, each with its size in KB and SMS segments and encoding.
- **Full-time digests** for every fan, sized to what was left of their budget.

The header of each file names the model that wrote the text. `offline-templates` means the run used the
deterministic offline backend (same agents and workflow, template text); a model name means a live model wrote
it.

## Reproduce

On the live site: open `/live`, pick the storyline, press **Kick off**, then **Jump → FT**. Tap **why?** under
any message, or any key moment, to see the same facts, source events and agent steps as in these files.

Locally (PowerShell, from `backend/` with the virtual environment active):

```powershell
python -m app.record                          # all four storylines
python -m app.record --storyline late_drama   # just one
```

With a model configured in `.env`, the recording uses it; without one, the offline templates.
